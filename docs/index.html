Built for frontend developers

The MVP stays focused: detect what is exposed by the page, compare it with current npm releases, and explain the result without pretending that an upgrade is mandatory.

Deterministic detection

Uses runtime globals, script URLs, stylesheet links, and framework metadata to reduce false positives.

Live npm versions

Checks the public npm registry for the latest published package version instead of relying on a manually maintained list.

SemVer-aware

Compares numeric major, minor, patch, and pre-release versions correctly.

Major vs minor

Distinguishes major-version changes from regular updates so the impact is clearer.

Local-first

Website details stay in the browser. npm receives only the package name needed for version lookup.

Graceful failures

If a version is unknown or npm is unreachable, the detector reports that state instead of guessing.

Privacy & support

Website Upgrade Detector is designed as a client-side developer utility. It does not require an account or backend service.

Privacy

The extension does not transmit webpage URLs, DOM content, browsing history, cookies, credentials, or telemetry. For npm version checks, only the public package name is requested from the npm registry.
