Privacy Policy — Website Upgrade Detector

Developer: SkyDevLab
Last updated: September 28, 2026

What the extension does

Website Upgrade Detector analyzes libraries exposed or referenced by the current webpage and compares detected versions with the latest published versions available from npm.

Data handling

The extension does not collect or transmit webpage URLs, browsing history, DOM content, cookies, credentials, form values, personal identifiers, or telemetry.

Npm requests

When checking a package, the extension makes a request to the public npm registry using only the npm package name. The website URL and page contents are not included in the request.

Local storage

Latest version results may be cached locally in the browser for a limited period to reduce repeated requests.

Third parties

There are no advertising SDKs, analytics services, or remote code dependencies bundled with the extension.

Contact

For questions or bug reports, use GitHub Issues.
